# Позиционный тренажёр

Персональный шахматный тренажёр, собранный по 207 партиям игрока **Fem_T_o** (lichess, 31.08–08.10.2026) и плану занятий «стабильность вместо разброса».

**Открыть:** https://crxscent.github.io/chess-trainer/

## Что внутри

- **Тренировка дня (30–45 мин):** позиционные задачи → профилактика → реализация и эндшпиль → дебюты.
- **Мои ошибки:** позиции из собственных партий, где ход стоил оценки. Каждая задача проходит протокол мышления: *что хочет соперник → худшая фигура → твой ход → разбор*. Категории: профилактика, проверка CCT, «нужен ли пешечный ход?», «активный ≠ хороший», реализация перевеса, план без тактики, эндшпиль.
- **Школа плана:** авторские задачи «найди план» в структурах репертуара (Карлсбад, изолятор, французские цепи, испанский манёвр Nf1–g3) и на технику эндшпиля.
- **Дебюты:** гамбит Гёринга, испанская, Алапин, французская, ферзевый гамбит (+ QGD за чёрных). Линии проверены Stockfish, учатся со стрелками, повторяются по памяти.
- **Разбор партии:** загрузка своих партий с lichess, разбор сначала *без движка* (первое ухудшение, план, идея соперника, кандидаты, самооценка по 5 пунктам), затем проверка встроенным Stockfish и создание новых упражнений из своих ошибок.
- **Дневник, диагноз, прогресс.**

## Прогресс и повторения

Интервальное повторение (SM-2-подобное): уверенно решённое возвращается через дни и недели, ошибки — завтра. Задача считается освоенной при интервале от 3 недель. Прогресс хранится в браузере (localStorage); в «Настройках» есть экспорт/импорт файла для переноса между устройствами.

## Сборка

```bash
npm install
npm run build          # src/ -> assets/app.js
```

Данные (`data/*.json`) генерируются скриптами в `tools/` (Python + python-chess + Stockfish):

```bash
python tools/build_openings.py                      # tools/openings/*.pgn -> data/openings.json
python tools/build_lessons.py                       # tools/lessons_src.py -> data/lessons.json
python tools/build_exercises.py analysis.json deep.jsonl   # -> data/exercises.json, data/diagnosis.json
```

Доска — [chessground](https://github.com/lichess-org/chessground) (GPL-3.0), правила — [chess.js](https://github.com/jhlywa/chess.js), движок в браузере — [stockfish.js](https://github.com/niklasf/stockfish.js) (GPL-3.0).
